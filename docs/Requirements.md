# Codexo — Requirements

> **Status:** NOT IMPLEMENTED (stub created in M0)

## Product Vision

Codexo is a Chrome extension that reads DSA problems and provides progressive, problem-specific hints — never the full solution.

## Target Users

- Software engineering students preparing for coding interviews
- Developers practicing DSA on platforms like LeetCode

## Non-Functional Requirements

- Response time: hints delivered within 3 seconds
- Accessibility: WCAG 2.1 AA compliance
- Security: no secrets in client, server-authoritative hint levels
- Privacy: minimum data collection with defined retention policy
